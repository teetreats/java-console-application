# java-console-application
Simple console-based soup list manager built in Java.

## Features
- **Add Soup (`1`):** Append a new soup entry to the dynamic list.
- **Remove Soup (`2`):** Search and remove an existing soup ("pour out") with feedback on item existence.
- **Edit Soup (`3`):** Update an existing soup name directly in the collection.
- **Display Soups (`4`):** Output all currently stored soups.
- **Exit (`5`):** Print the final list summary and terminate execution.
- **Empty-state Validation:** Safeguards against performing operations on an empty collection.
